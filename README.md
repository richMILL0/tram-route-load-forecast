# Прогноз загруженности трамвайных маршрутов Москвы

Веб-сервис для прогнозирования пассажиропотока по 10 трамвайным маршрутам Москвы. Пользователь выбирает маршрут, задаёт начало и конец периода и получает прогноз общего количества посадок и среднего количества посадок в час. Результат отображается на карте и в списке маршрутов.

## Архитектура

Проект состоит из трёх сервисов:

- `frontend` — React 19, TypeScript, Vite, MapLibre и OpenFreeMap;
- `backend` — Java 21, Spring Boot 4.1.1, Spring WebFlux;
- `fastapi-stub` — Python 3.12, FastAPI и ансамбль из 10 CatBoost-моделей.

Поток запроса:

```text
Browser
   │
   V
Frontend
   │ POST /api/v1/routes/{routeId}/forecast
   V
Spring Boot
   │ POST /predict/forecast
   V
FastAPI + CatBoost ensemble
   │
   V
Forecast result
```

## Запуск

Требуется Docker с поддержкой Docker Compose.

```bash
docker compose up --build
```

После запуска интерфейс доступен по адресу:

```text
http://localhost:3000
```

Проверка Java backend:

```text
http://localhost:3000/api/v1/health
```

Проверка FastAPI:

```text
http://localhost:8000/health
```

Порт FastAPI не публикуется наружу в Compose, поэтому этот endpoint доступен непосредственно только внутри Docker-сети.

## Прогноз

Пользователь может задать любую дату от `01.01.2025` до `31.12.2026` и интервал длительностью не более одного календарного месяца.

Модель имеет часовую гранулярность. Например, запрос с границами `09:05` и `18:07` использует часовые корзины от `09:00` до `18:00` включительно.

FastAPI получает запрос:

```json
{
  "ngpt_route": 17,
  "start_datetime": "2026-09-27T09:05:00",
  "end_datetime": "2026-09-27T18:07:00"
}
```

Результат содержит:

```json
{
  "routeId": 17,
  "startDate": "2026-09-27T09:05:00",
  "endDate": "2026-09-27T18:07:00",
  "boardings": 101000.0,
  "boardingsPerHour": 1000.0,
  "loadLevel": "HIGH",
  "generatedAt": "2026-09-27T15:00:00+00:00"
}
```

`boardings` — сумма почасовых прогнозов за выбранный период.

`boardingsPerHour` — `boardings / фактическая длительность интервала в часах`. Именно это значение используется для определения уровня нагрузки.

## Уровни нагрузки

Текущие пороги рассчитаны по квартилям исторического распределения `lag_mean` в данных, использованных при обучении модели.

| Посадок в час | Уровень |
|---:|---|
| `≤ 201` | Низкая |
| `202–677` | Средняя |
| `678–1468` | Высокая |
| `> 1468` | Критическая |

Классификация выполняется в FastAPI. Frontend получает готовый `loadLevel` и использует его только для визуализации.

## ML-модель

В `fastapi-stub/model` находятся артефакты Data Science:

- 10 моделей CatBoost в формате `.cbm`;
- `lag_features_final.csv`;
- `lag_features_coarse_final.csv`;
- `weather_2025.csv`.

Модели загружаются один раз при запуске FastAPI. Для каждого запроса выполняется прогноз всеми 10 моделями, после чего результаты усредняются.

Обучающие данные относятся к 2025 году. Лаговые признаки являются историческими агрегатами по маршруту, дню недели и часу, а не рекурсивными предыдущими предсказаниями. Поэтому прогнозы на 2026 год используют исторический сезонный сигнал из этих признаков.

## Погода

Используется следующая схема:

1. Для дат 2025 года используется `weather_2025.csv`.
2. Для дат 2026 года, находящихся не более чем в 14 днях от текущей даты по Москве, используется Open-Meteo Forecast API.
3. Для остальных дат 2026 года используется погода той же календарной даты 2025 года.
4. Полученные данные Open-Meteo кэшируются внутри контейнера.
5. При недоступности Open-Meteo используется fallback на соответствующую дату 2025 года.

Координаты погодного запроса соответствуют Москве: `55.75, 37.62`.

## Карта

Frontend использует MapLibre с векторным стилем OpenFreeMap.

При выборе маршрута:

- карта автоматически приближает выбранный маршрут и показывает его целиком;
- отображаются реальные геометрия и остановки из OpenStreetMap, если Overpass API доступен;
- при недоступности Overpass API карта сохраняет базовую геометрию маршрута, полученную от Java backend;
- линия маршрута имеет тонкую чёрную обводку;
- цвет линии определяется уровнем нагрузки;
- остановки показываются точками и отображают название при наведении.

## API

### Получить маршруты

```http
GET /api/v1/routes
```

Ответ — GeoJSON `FeatureCollection` с геометрией и названиями 10 маршрутов.

### Получить прогноз

```http
POST /api/v1/routes/{routeId}/forecast
Content-Type: application/json
```

Тело:

```json
{
  "startDate": "2026-09-27T09:05:00",
  "endDate": "2026-09-27T18:07:00"
}
```

Java проверяет маршрут и диапазон дат, затем передаёт запрос FastAPI.

### Healthcheck

```http
GET /api/v1/health
```

FastAPI:

```http
GET /health
```

## Конфигурация frontend

```text
VITE_API_BASE_URL=/api/v1
```
